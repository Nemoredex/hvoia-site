## 1. Замечания Lighthouse и что сделано

Исходный прогон: Performance 89, Accessibility 97, Best Practices 96, SEO 100 (DevTools, главная).

## 3. Что не проверено и почему

- **Lighthouse из командной строки.** В Chrome и Edge на этом компьютере удалённая отладка запрещена системной политикой, а Lighthouse CLI без неё не работает. Обходить политику не стали. Прогнать вручную: `npm run build`, затем `npm run serve`, затем Chrome в инкогнито → `http://localhost:4322/` → DevTools → Lighthouse → Mobile. Повторить для каждой страницы.
- **Скорость в поле (LCP, INP).** Локально нет задержек сети, поэтому цифры ничего не значат. Проверять после выкладки в PageSpeed Insights и в Метрике.
- **Валидаторы микроразметки Яндекса и schema.org** — до localhost не достают, только после выкладки. Чек-лист в [DEPLOY.md](DEPLOY.md), раздел 3.
- **Доставка заявок в Telegram и на почту** — нужны токены в `.env`.
- **nginx** — на сервере обязательно `nginx -t`. После выкладки — `node scripts/check-server.mjs https://www.hvoia-event.ru`: тот же набор проверок плюс зеркала http и без www.

## 4. Для SEO-команды

- **Где менять:**
  - title и description — `src/data/seo.ts`; title до 60 символов вместе с « — «Хвоя»», description 140–160;
  - факты (цены, телефоны, адрес, FAQ) — `src/data/`;
  - тексты блоков — в страницах `src/pages/`.
- **После любой правки:** `npm run verify` — типы, сборка, редиректы, HTML и строгий SEO-отчёт.
- **Страницы:** 8 в sitemap (`/sitemap-index.xml`). 404 отдаёт настоящий код 404.
- **URL:** латиница, со слэшем на конце; без слэша — 301 на адрес со слэшем.
- **Старый сайт:** карта 301 — `_migration/old-urls.csv`, 41 адрес. Новые адреса из «Исключённых» Вебмастера дописывать туда, затем `npm run redirects`.
- **robots.txt:** Sitemap и `Clean-param` для UTM, yclid, gclid и других рекламных меток.
- **Разметка JSON-LD:**

  | Страница | Типы |
  |---|---|
  | Главная, контакты | LodgingBusiness |
  | Главная | WebSite |
  | Коттедж | House |
  | Свадьбы, праздники | EventVenue |
  | Цены | OfferCatalog |
  | Фото | ImageGallery |
  | Где есть вопросы | FAQPage |
  | Внутренние | BreadcrumbList |

  Рейтинга в разметке нет намеренно: он есть только в карточке Яндекс Карт, а скопированные вручную цифры устареют.
- **Метрика:** номер счётчика — `PUBLIC_METRIKA_ID` в `.env`, затем пересборка. Цели: `lead`, `phone`, `messenger`, `booking`. Вебвизор выключен.
- **Карта и отзывы Яндекса** грузятся, только когда до них долистали, поэтому Lighthouse при загрузке их не видит. Так и задумано.
- **Водяные знаки** («170 м²», «круглый год») — декор в CSS, не текст: в индекс они не попадают.

## Команды

```bash
npm run build           # сборка
npm run serve           # сервер как на проде, localhost:4322 — для Lighthouse
npm run seo             # сборка + seo-report.html
npm run validate:html   # валидность HTML
npm run check:server    # коды ответов, 301, 404, сжатие, кеш (можно с адресом боевого сайта)
npm run verify          # всё перед выкладкой, строго
```

Служебные скрипты (запускать, только если меняются исходные картинки): `node scripts/make-decor.mjs` — маска леса, `node scripts/make-hero-crops.mjs` — кадры первого экрана для телефона.
