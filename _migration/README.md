# Переезд со старого сайта www.hvoia-event.ru

Черновик карты редиректов для этапа 9 (см. `PLAN.md`). Собрано 19.11.2026 из открытых данных старого сайта.

## Что проверено

- **Главное зеркало — `https://www.hvoia-event.ru/`.** `http://` и `https://hvoia-event.ru/` отдают 301 на него. Новый сайт оставляем на том же зеркале, поэтому «Переезд сайта» в Вебмастере не нужен.
- **Старый сайт работает на Drupal.** В `sitemap.xml` 13 URL, все без слэша на конце. В robots.txt нет директивы `Sitemap`.
- **`/policy`, PDF с правилами, `/portfolio`, `/service`, `/services` отвечают 200**, хотя их нет в sitemap.
- **Узлы `/node/N` тоже отвечают 200.** Это дубли: canonical у каждого указывает на ЧПУ.
- В title старых внутренних страниц «Xвoя» набрано латинскими X и o. На новом сайте везде кириллица.

## Файлы

- `old-urls.csv` — старый URL, его title, новый URL, комментарий. Разделитель — `;`.
