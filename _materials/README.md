# Гостевой дом «Хвоя»: многостраничный прототип

Дизайн, тексты и фото взяты из исходного прототипа. Инлайн-стили перенесены в классы, значения сохранены 1:1. Страницы открываются двойным кликом из папки.

## Страницы

| Файл | Содержание | Маршрут в Astro |
| --- | --- | --- |
| index.html | исходная главная: проверка дат, «Отдых / Праздник», территория, маршрут, форматы, бронирование, фото, FAQ, заявка | `src/pages/index.astro` |
| kottedzh.html | дом и комнаты, удобства, территория, цены проживания, как забронировать, FAQ | `src/pages/kottedzh.astro` |
| svadby.html | что входит, тёплый шатёр, этапы подготовки, галерея, FAQ | `src/pages/svadby.astro` |
| prazdniki.html | дни рождения, юбилеи, корпоративы, что можно заказать, отдых после банкета | `src/pages/prazdniki.astro` |
| ceny.html | проживание, доп. гости, залог и бронирование, события по смете | `src/pages/ceny.astro` |
| foto.html | галерея с фильтром «Дом / Территория / Праздники / Зима» и отзывы | `src/pages/foto.astro` |
| kontakty.html | маршрут, контакты, карта, как доехать, реквизиты | `src/pages/kontakty.astro` |

## Как устроено

- **Данные.** Все цены, условия, удобства и FAQ лежат в `data/hvoia.json`. Всё в [квадратных скобках] нужно уточнить у заказчика.
- **Компоненты.** Каждый блок помечен комментарием `<!-- ====== COMPONENT: Имя (src/components/Имя.astro) ====== -->`.
- **Стили.** Все стили в `assets/css/style.css`, цвета и шрифты — в токенах `:root`.
- **Декор.** Полосы леса, ветка и шишка лежат в `assets/img/decor/`.
- **Скрипты.** `assets/js/main.js`: меню, фильтр фото, формы. Проверка дат показывает демо-сообщение — на сайте её нужно подключить к модулю онлайн-бронирования (TravelLine, Bnovo и т. п.).
- **SEO.** В разметке есть JSON-LD: `LodgingBusiness` на главной и `FAQPage` на страницах с вопросами.

## Фото

Все фото на месте. Новые снимки (дом зимой, бассейн днём, санузел, свадьба, шатёр, праздники, дорога) сгенерированы и годятся для прототипа — перед запуском лучше заменить их реальной съёмкой.

Фото организатора нужно настоящее, от заказчика.

## Исправления дизайна (18.11.2026)

Проверено на ширинах 320–1920 px.

1. Карточки «Дом» и «Какие праздники проводим» — инлайн-сетка заменена классом `.cards-3`; на телефоне теперь одна колонка, а не три сжатых.
2. Декоративные надписи (`.fade-number`) больше не обрезаются краем экрана; для длинных («круглый год») — модификатор `.fade-number--long`.
3. Бенто «Территория» на планшете (≤960 px) — 2 колонки вместо 4.
4. Шаги: большие цифры не наезжают на текст; на планшете шаги в один столбец.
5. Свадьбы, «Тёплый шатёр»: заголовок перенесён в колонку с текстом, дыра убрана.
6. У всех тёмных полос `.packages` добавлен силуэт леса снизу (`edge--bottom`), как у остальных переходов.
7. Тарифы на планшете идут столбиком, без растянутой третьей карточки.
8. Фото: сетка без пустых ячеек (`grid-auto-flow: dense` + порядок карточек).
9. Убраны повторы фото на одной странице (главная, Коттедж, Праздники, Фото).
10. Кнопка «Проверить свободные даты» не переносится; на телефоне даты заезда/выезда стоят в одну строку.
11. Подписи маршрута — сетка `auto 1fr auto`, средняя по центру.
12. Мобильная заявка: форма идёт первой, заглушка фото ниже и короче.
13. Прайс: числа не рвутся (`&nbsp;`), длинные значения переносятся аккуратно.
14. Неразрывные пробелы после коротких слов в заголовках.
15. `width/height` у всех картинок совпадают с реальными размерами (нет сдвигов макета).
16. `main.js`: удалён код из другого проекта; дата выезда не может быть раньше заезда.

## Переходы первого экрана (19.11.2026)

У каждой страницы свой переход от героя к контенту (классы в `style.css`, блок «Переходы первого экрана»):

| Страница | Переход | Разметка |
|---|---|---|
| Главная | «Лес» — два ряда сосен перетекают в тёмную полосу без шва | `.trees--back`, `.trees--front` |
| Коттедж | «Поляна» — мягкий холм | `.hero__edge--hill` (SVG) |
| Свадьбы | «Туман» — лес растворяется в дымке | `.hero--mist` + `.hero__edge--mist` |
| Праздники | «Гирлянда» — огоньки над краем шатра | `.hero__edge--garland` (`garland.svg`, `scallop.svg`) |
| Цены | «Сугроб» — снег и неровный край | `.hero__snow` + `.hero__edge--drift` |
| Фото | «Рамка» — без деревьев, снимок с закруглённым низом | `.hero--frame.hero--flat` |
| Как добраться | «Дорога» — без деревьев, пунктир маршрута и метка | `.hero--flat` + `.hero__edge--road` |

Шишки на схеме маршрута стоят точно на кривой, с равным шагом, на белой подложке, которая разрывает пунктир.
